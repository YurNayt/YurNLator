# YurNLator 1.0.1

## Что нового
- **Палитра оформления.** В Настройки › Оформление можно выбрать цвет всего интерфейса (фон, карточки, панели, контуры) и отдельно цвет акцента (кнопки, переключатели, выделение). Есть готовые цвета, включая насыщенный оранжевый, и цветовой круг для любого своего цвета.
- **Контейнер для установки игр (setup / репаки).** При создании контейнера можно выбрать тип «Для установки игр»: Proton 9.0 x86_64, параметры трансляции «Совместимость», Box64 0.3.9. Недостающие компоненты скачиваются сами. Эти настройки подходят не для каждого установщика.
- **Новые пресеты Box64 и FEX** из Bannerlator и DroidDeck:
  - Box64: Производительность (Mali), Экстрим, Экстрим 2, Unity, Unity (Mono bleeding edge), Denuvo;
  - FEX: Производительность (TSO), Производительность (полный x87), Экстрим-wn, Экстрим (TSO)-wn, Экстрим-gn, Denuvo, Unreal Engine 3.

## Исправлено
- **Загрузка обновлений.** Загрузка больше не запускается дважды и не ломается, если закрыть окно, свернуть приложение, выключить экран или переключить VPN. Она продолжается с того же места, а скачанный APK проверяется перед установкой.
- Кнопки паузы и отмены загрузки разнесены дальше друг от друга.
