# YurNLator 1.0.0

Первая основная версия YurNLator — эмулятора Windows-игр для Android на основе Winlator Ludashi, с функциями Bannerlator, GameNative и Winlator Mali.

## Главное
- **Новый интерфейс:** библиотека игр с обложками, страницы игр и контейнеров, вертикальный и горизонтальный режимы, темы оформления (включая зелёную).
- **Русский и английский язык** (Настройки › Оформление › Язык приложения) и **справочник по настройкам**: «?» рядом с каждой настройкой.
- **Быстрое меню в игре:** HUD (YurNLator, стили Bannerlator, MangoHud), ограничитель FPS, генерация кадров (Win-FG, WFG, LSFG со своим Lossless.dll), масштабирование и эффекты экрана, управление, гироскоп, диспетчер задач.
- **Производительность:** режим стабильной производительности, большие ядра, фиксация частоты GPU (Adreno без root, MediaTek с root), защита от перегрева.
- **Бенчмарк:** подбор лучшей связки драйвер / DXVK / FEX / Box64 для телефона и замер встроенных бенчмарков игр.
- **Mali «из коробки»:** Vulkan-обёртка, слой BCn, барьеры Mali, счётчики Mali в HUD.
- **Компоненты:** Wine / Proton (включая Proton 11 arm64ec), DXVK, VKD3D, FEX 2611, Box64 0.4.5, Turnip 27, D7VK; загрузки с паузой, продолжением и отменой; компоненты Windows ставятся прямо в контейнер.
- **Пресеты сообщества:** готовые настройки игр от других игроков и публикация своих.
- **Обновления в приложении:** Настройки › О программе › Обновление.

## Варианты APK
- `standard` — обычный YurNLator.
- `antutu`, `antutuAlt`, `ludashi`, `ludashi2`, `genshin`, `pubg`, `geekbench6`, `vivo` — та же программа под именем другого приложения: телефоны, которые разгоняют процессор для бенчмарков и игр (MediaTek, Unisoc и др.), запускают её на полных частотах. Каждый вариант ставится как отдельное приложение.

Тестовые сборки (канал dev) выходят только в вариантах `standard` и `antutu`.
