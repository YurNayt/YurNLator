# YurNLator 1.0.0

## Основа
YurNLator сделан на основе **Winlator Ludashi 4.1** (StevenMX, pipetto-crypto) — форка Winlator (brunodev85) через Winlator CMOD (coffincolors) и glibc-форк longjunyu2. Часть функций перенесена из **Bannerlator** (The412Banner), **GameNative**, **Winlator Mali** и **Ludashi 5.0**.

## Основные изменения
- Новый интерфейс: библиотека игр с обложками, страницы игр и контейнеров, вертикальный и горизонтальный режимы, темы оформления.
- Русский язык и справочник по всем настройкам.
- Быстрое меню в игре: HUD (YurNLator, стили Bannerlator, MangoHud), ограничитель FPS, генерация кадров (Win-FG, WFG, LSFG), масштабирование и эффекты экрана, управление, гироскоп, диспетчер задач.
- Производительность: режим стабильной производительности, большие ядра, фиксация частоты GPU (Adreno без root, MediaTek с root), защита от перегрева.
- Бенчмарк: подбор лучшей связки драйвер / DXVK / FEX / Box64 и замер встроенных бенчмарков игр.
- Поддержка Mali из коробки: Vulkan-обёртка, слой BCn, барьеры Mali, счётчики Mali в HUD.
- Обновлённые компоненты: Proton 11 arm64ec, FEX 2611, Box64 0.4.5, Turnip 27, D7VK; загрузки с паузой и отменой, компоненты Windows ставятся прямо в контейнер.
- Пресеты сообщества — готовые настройки игр от других игроков.
- Обновление прямо из приложения.
- Варианты APK под имена других приложений (AnTuTu и др.), на которых телефоны дают полные частоты.
