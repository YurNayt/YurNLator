# YurNLator 1.1.1

## Новое
- **Запуск от имени администратора**:
  - переключатель «Запускать программы от имени администратора» в настройках контейнера (включён по умолчанию);
  - разовый запуск с правами администратора — кнопкой рядом с «Играть» на странице игры и из меню игры в библиотеке.
- **Новая страница игры** (в стиле Winlator Ludashi 5.0): обложка с самого верха экрана, плитки «Наиграно», «Запусков», «Последний запуск», «Размер папки» и «Магазин», кнопки «Играть» и «От имени администратора»; в альбомной ориентации действия справа.
- **Уведомление о геймпаде**: как только геймпад подключён, сверху появляется уведомление, а экранные кнопки скрываются; после отключения они возвращаются. Уведомление можно смахнуть вверх или закрыть нажатием.
- **Драйверы RADV для Samsung Xclipse** (JimVulkan) в загрузках драйверов.
- **DLL для отдельных программ** (Настройки ярлыка → Дополнительно): например, лаунчеру — Direct3D от Wine, а самой игре — DXVK.
- **Окно добавления переменной окружения** переделано: имя вводится сразу, известные переменные открываются стрелкой, значение — строкой ниже. Если такая переменная уже есть, это видно сразу (раньше кнопка «Добавить» в этом случае молча не срабатывала).
- В логе запуска видно, какой эмулятор работает (FEXCore / WOWBox64), его версия, пресет и переменные контейнера и ярлыка.

## Исправлено
- **Запуск игр Steam через Ubisoft Connect** (например, Far Cry 3; может работать не на всех устройствах):
  - игра из Steam видна Ubisoft Connect как установленная, лаунчер больше не пытается скачать её заново;
  - перед запуском записывается реестр из установочного скрипта Steam (ошибка «Cannot find essential information in the registry»);
  - служба RpcSs запускается по требованию (ошибка «Failed to start RpcSs service»);
  - FC3UpdaterSteam больше не вылетает через ~10 секунд после старта;
  - Ubisoft Connect больше не вылетает из-за шрифтов Wine для DirectWrite;
  - HUD больше не показывает «DX12» для DX11-игры из-за проверки DX12 лаунчером.
- **Переработаны анимации и внешний вид**:
  - переключение вкладок — одним плавным переходом, заголовок и кнопки сверху меняются вместе с экраном;
  - страница игры выезжает поверх библиотеки и уезжает обратно, без рывков и мигания;
  - все окна выбора (драйверы, Proton, DXVK, пресеты и др.) выезжают плавно и одинаково, без замираний посреди анимации; их можно смахнуть вниз;
  - быстрое меню в игре можно закрыть свайпом влево;
  - группы версий и списки раскрываются плавно;
  - на странице магазина больше нет лишней полосы «Магазины» сверху;
  - кнопки значений в пресетах Box64 / FEX ярче и плотнее.
- **Библиотека**: каждая категория открывается с начала списка (раньше «Недавние» могли открыться с конца); при переключении вида сетка / список не мигают верхняя панель и обложки.
